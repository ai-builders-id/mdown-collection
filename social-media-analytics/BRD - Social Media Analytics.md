# BRD: SosmedInsight — Business Requirements
**Project:** SosmedInsight

## 1. Latar Belakang & Konteks Bisnis
Media sosial telah menjadi saluran pemasaran utama bagi bisnis di Indonesia. Berdasarkan data We Are Social 2025, pengguna media sosial aktif di Indonesia mencapai 212 juta orang — menempati peringkat ke-3 dunia. Namun, banyak brand dan bisnis masih mengelola akun media sosial mereka secara intuitif tanpa data yang akurat.

Permasalahan utama yang dihadapi:
- **85% UKM** di Indonesia tidak memiliki alat analitik media sosial yang memadai
- **70% social media manager** mengandalkan insight bawaan platform yang terbatas dan tidak terintegrasi
- **60%** kesulitan mengukur ROI dari aktivitas media sosial
- **45%** tidak bisa membandingkan performa dengan kompetitor

SosmedInsight hadir sebagai dashboard analitik multi-platform yang menyajikan data follower growth, engagement, reach, dan metrik konten dalam satu antarmuka terpadu berbahasa Indonesia, dengan harga terjangkau untuk UKM dan enterprise di Indonesia.

## 3. Value Proposition

**Untuk Social Media Manager / Marketing:**
- Satu dashboard untuk semua platform — tidak perlu buka 6 aplikasi berbeda
- Insight audiens mendalam: siapa pengikut Anda, kapan mereka aktif, konten apa yang mereka suka
- Perbandingan kompetitor otomatis — tahu persis posisi Anda di pasar
- Laporan siap presentasi dalam 1 klik — hemat waktu 5 jam/minggu

**Untuk Pemilik Bisnis / Founder:**
- Lihat ROI media sosial dalam angka yang jelas
- Tahu konten mana yang benar-benar menghasilkan leads/penjualan
- Dashboard eksekutif dengan metrik kunci tanpa noise
- Rekomendasi berbasis data untuk strategi konten

**Untuk Agency / Freelance:**
- Manajemen multiple client dalam satu akun
- Laporan white-label untuk klien
- Benchmark antar client dan industri
- Jadwal posting dan approval workflow

## 6. Model Distribusi
SosmedInsight adalah **Software-as-a-Service (SaaS)** berbasis web dengan model freemium:

**Tier Gratis:**
- 1 akun media sosial
- Data 7 hari terakhir
- Metrik dasar (followers, likes, comments)
- 1 laporan PDF/bulan

**Tier Pro (Rp 99.000/bulan):**
- 3 akun media sosial
- Data 12 bulan history
- Semua metrik + grafik
- Insight audiens lengkap
- Laporan PDF tak terbatas
- Perbandingan kompetitor (3 kompetitor)
- Export data CSV

**Tier Business (Rp 299.000/bulan):**
- 10 akun media sosial
- Data unlimited history
- Team collaboration (5 user)
- API akses
- White-label report
- Prioritas support (WA + telepon)
- Content scheduling

**Tier Enterprise (Rp 999.000/bulan):**
- Unlimited akun
- Unlimited user
- Custom integration
- SLA 99.9%
- Dedicated account manager
- On-premise option

## 8. Analisis Kompetitor

| Kompetitor | Kelebihan | Kekurangan | Posisi Kami |
|------------|-----------|------------|-------------|
| **Hootsuite** | Multi-platform, scheduling, team collab | Mahal ($99+/bulan), tidak fokus Indonesia, UI kompleks | Harga lebih murah, bahasa Indonesia, fometrik UKM |
| **Buffer** | Simple, mudah digunakan, scheduling | Analytics terbatas di tier murah, tidak ada kompetitor | Analytics lebih lengkap, ada kompetitor comparison |
| **Sprout Social** | Analytics mendalam, laporan kaya | Sangat mahal ($249+/bulan), Inggris saja | Harga 10x lebih murah, insight audiens Indonesia |
| **Native Insights (IG/TikTok)** | Gratis, data real-time | Terbatas per platform, tidak ada history panjang, tidak bisa bandingkan | Multi-platform, history 12 bulan, perbandingan |
| **SocialBlade** | Data publik siapa pun | Tidak real-time, hanya estimasi, UI usang | Real-time, akurat, UI modern |
| **NapoleonCat** | Moderasi komentar, inbox sosial | Mahal, kurang fokus analitik | Fokus analitik + harga lebih terjangkau |

**Keunggulan kompetitif SosmedInsight:**
- 100% Bahasa Indonesia — dari UI hingga laporan
- Insight otomatis dalam bahasa sehari-hari: "Pengikut Anda bertambah 15% minggu ini"
- Harga terjangkau untuk UKM Indonesia — mulai gratis
- Perbandingan kompetitor yang akurat dengan data real
- Laporan PDF siap presentasi dengan brand klien

## 9. Risiko & Mitigasi

| Risiko | Dampak | Probabilitas | Mitigasi |
|--------|--------|--------------|----------|
| Perubahan API platform sosial media | Tinggi | Tinggi | Monitoring changelog platform, fallback manual sync, abstraction layer API |
| Data tidak akurat karena rate limiting | Sedang | Sedang | Caching strategis, estimasi cerdas, notifikasi jika data delay |
| Keamanan data akses token | Tinggi | Rendah | Encryption token, refresh token otomatis, never store di client |
| Kompetitor tiru fitur | Sedang | Tinggi | Fokus pada kualitas data dan local insight, bangun komunitas |
| Adopsi rendah karena kebiasaan | Sedang | Sedang | Campaign edukasi, webinar gratis, migration tools |
| Biaya server tinggi karena scrap data | Tinggi | Sedang | Optimasi query, caching agresif, prioritaskan platform dengan API resmi |
